# VidyarthiBus

VidyarthiBus is an Android application developed to help students track college buses, check seat availability, and manage their profiles in real time.

## Features

- User Registration and Login using Firebase Authentication
- Student Dashboard
- Admin Dashboard
- Bus Tracking
- Seat Availability Monitoring
- Profile Management
- Real-time Data Storage using Cloud Firestore

## Technologies Used

- Kotlin
- Jetpack Compose
- Firebase Authentication
- Cloud Firestore
- Android Studio
- GitHub
- GenAI

## Problem Statement

Students often face difficulty in tracking college buses and checking seat availability. This application provides a convenient way to view bus details, monitor seat availability, and manage profiles from a single mobile platform.

## Project Structure

- `app/` - Application source code
- `gradle/` - Gradle wrapper files
- `build.gradle.kts` - Build configuration
- `settings.gradle.kts` - Project settings

## How to Run the Project

1. Clone the repository.
2. Open the project in Android Studio.
3. Add your own `google-services.json` file to the `app/` folder.
4. Sync Gradle.
5. Run the application on an emulator or Android device.
